# HealthBar profanity / slur denylist (UGC-1a).
#
# Format (D9): one lowercase term per line. Lines starting with `#` and blank
# lines are ignored. Matching is a SUBSTRING scan over the caller's normalized
# input (lowercased, diacritic-folded, leetspeak-mapped, non-a–z stripped), so
# a root such as `fuck` also catches `fucker`, `motherfucker`, `fuckface`, etc.
#
# AUTHORING RULES — read before adding a term:
#   * Every entry MUST be >= 4 characters. Short terms + substring matching =
#     Scunthorpe false positives.
#   * NEVER add a term that is a common English word or a common substring of
#     ordinary names. (Excluded for exactly this reason: dick → Dickinson,
#     cock → peacock, coon → raccoon, arse → coarse, chink → "a chink in", crap
#     → scrap, rape → grape, rapist → therapist, pedo → torpedo, anus → Uranus,
#     kraut → sauerkraut, paki → Pakistan, shag → shaggy, knob → door knob.)
#   * Prefer the root form; substring matching covers inflections.
#
# This is v1: English only, no full confusable-script mapping. Moderation of
# anything this misses is handled by the report path + block path.
